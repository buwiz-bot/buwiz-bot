# D&B Risk Analytics connector setup

Checked 2026-10-25 against live endpoints, D&B's public pages and the plugin repo. D&B's authentication guide is on Highspot and could not be read (it redirects to an unsupported-browser page), so anything about credential creation beyond the README is **(unconfirmed)**.

## What it unlocks

Buwiz Bot connects to the D&B Risk Analytics MCP server at `https://agents.riskanalytics.dnb.com/mcp`. It exposes a Risk Analytics agent as a tool that can read and write: company insights, KYC/KYB, beneficial ownership and family trees, screening, adding entities to a portfolio, managing users, tags and custom fields.

No dynamic client registration. Credentials are per Risk Analytics workspace, generated by an admin. The catalog's `CLIENT_ID` / `CLIENT_SECRET` are env-var placeholders (`DNB_RA_MCP_CLIENT_ID`, `DNB_RA_MCP_CLIENT_SECRET`), not a shared vendor app.

Endpoints (confirmed live; `https://agents.riskanalytics.dnb.com/.well-known/oauth-authorization-server` and `.../oauth-protected-resource/mcp`):

| Item | Value |
|---|---|
| MCP server | `https://agents.riskanalytics.dnb.com/mcp` (POST without a token: 401, `WWW-Authenticate: Bearer ... resource_metadata=".../.well-known/oauth-protected-resource/mcp"`; a bare GET returns 400 "Missing mcp-session-id header") |
| Authorization server (issuer) | `https://agents.riskanalytics.dnb.com` |
| Authorize URL | `https://agents.riskanalytics.dnb.com/authorize` |
| Token URL | `https://agents.riskanalytics.dnb.com/token` |
| PKCE | `S256`, `plain` |
| Token endpoint client auth | `client_secret_basic`, `client_secret_post` (secret required) |
| Grants | `authorization_code`, `refresh_token`, `client_credentials` |
| `scopes_supported` | `offline_access`, `openid`, `email`, `profile`, `mcp.read`, `mcp.write` |
| `registration_endpoint` | none |

## Prerequisites

- An existing D&B **Risk Analytics** workspace and an account that can administer it (README: "In your Risk Analytics workspace, go to Admin -> Integrations -> API"). Whether that menu needs a specific admin role or a plan add-on is **(unconfirmed)**.
- Price and eligibility: not published; D&B's launch press release (July 2026) and plugin page do not say whether access is limited to Risk Analytics customers. Contact **CursorLeads@dnb.com**, the form at https://www.dnb.com/en-us/solutions/artificial-intelligence/connectors/cursor-dnb-risk-analytics-plugin.html, or phone (855)-540-1971 (listed on that page, purpose not stated).
- You sign in at the end with your **Risk Analytics email address**.

## Steps

1. Sign in to your Risk Analytics workspace as an admin.
2. Go to **Admin -> Integrations -> API** and generate a **Client ID** and **Client Secret** (README wording). Name it `Buwiz Bot` if a name is requested **(field unconfirmed)**.
3. Look for a redirect/callback URI field on that screen. If present, enter `http://127.0.0.1:8787/oauth/callback/dnb-risk-analytics` (confirm in Buwiz Bot's plugin page). If there is none, ask D&B to register it; whether loopback `http://` is accepted is **(unconfirmed)**.
4. Copy the secret immediately (whether it is shown once is **unconfirmed**).

## What to paste into Buwiz Bot

Open **Connect apps -> D&B Risk Analytics** -> settings:

| Buwiz Bot field | Value |
|---|---|
| Client ID | from Admin -> Integrations -> API |
| Client Secret | from the same screen |
| Callback URL (read-only) | should equal `http://127.0.0.1:8787/oauth/callback/dnb-risk-analytics` |

Then click **Authenticate** and sign in with your Risk Analytics email.

## Scopes requested

From the catalog: `mcp.write mcp.read offline_access openid email profile` (identical to the server's `scopes_supported`). `mcp.write` lets the agent change your portfolio (add entities, users, screenings); drop it if Buwiz Bot lets you edit scopes and you want read-only.

## Alternative: client credentials

The token endpoint lists the `client_credentials` grant, so a machine token from the same Client ID/Secret may be possible, usable as `Authorization: Bearer` **(unverified: README documents only the interactive login; also acts as the integration, not as you)**. It needs a Buwiz Bot custom-header option.

## Verification

1. Buwiz Bot shows connected.
2. Ask: "Using D&B Risk Analytics, list the entities in my portfolio" (read only; costs no write).
3. Check the Risk Analytics admin area for the integration's activity **(unconfirmed)**.

## Troubleshooting

- **redirect mismatch**: D&B has not registered Buwiz Bot's callback; send them the exact URL.
- **invalid_client**: wrong secret, or credentials from another workspace/environment.
- **Login succeeds but no tools**: your user lacks Risk Analytics permissions; the MCP server acts with your permissions **(unconfirmed)**.
- **400 "Missing mcp-session-id header"** on a plain GET is normal.
